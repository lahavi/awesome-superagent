# Contribution Guidelines

Thanks for helping keep this list useful. Please read these guidelines before you open a pull request.

## What belongs here

A resource belongs on the list when it is about DeepSeek's SuperAgent (`dsh-superagent`) or directly helps people run, extend, understand, or secure it. Harness resources belong only when they matter to SuperAgent users. For everything else about DeepSeek Harness, see [awesome-deepseek-harness](https://github.com/calderbuild/awesome-deepseek-harness).

We do not accept:

- Copies or mirrors of the official repository with no changes of their own.
- Empty repositories, sandboxes, and throwaway test repositories.
- Jailbreak, prompt-injection, or credential-harvesting tools, unless they are clearly defensive research.
- Thin or AI-generated SEO articles that only restate the official README.
- Paywalled or sign-up-gated content, except major news outlets.

## Adding a resource

1. Search the list and the open pull requests to make sure the resource is not already there.
2. Add it to the end of the most fitting section, in this format:

   ```markdown
   - [Name](https://link) - Short description.
   ```

3. Keep the description short. Start it with a capital letter, end it with a period, and say what the resource does rather than how good it is.
4. Mark resources that are not in English, for example "in Chinese".
5. Use the resource's real name and link to its canonical page, not a tracking or shortened link.
6. Add one resource per pull request, and explain in the pull request why it belongs here.

## Updating the list

- Open an issue or pull request to fix a broken link, an outdated description, or a resource that no longer works.
- Suggest a new section only when at least three resources would go in it.

A weekly link check runs on this repository and opens an issue when it finds broken links.

By contributing, you agree to release your contribution under [CC0](LICENSE) and to follow the [Code of Conduct](code-of-conduct.md).
